ForgeAI

The agent that builds agents. Give it a one-paragraph brief and a folder of documents: it builds a RAG agent, writes its tests, grades it, fixes it, and reports honestly what still fails.

Brief→Intake→Groundability guard→Generate agent→Generate evals→Judge→Critic + optimizer ×3→Honest report
checking live model…

ForgeAI is a pipeline that runs unattended on small open models (built and evaluated with qwen2.5:3b-instruct + llama3.2:3b via Ollama on a 4 GB GPU). The factory runs locally. A full build takes 15–40 minutes, longer than a serverless request allows, so this site shows the committed evidence and lets you chat with the agents it produced.

Run the factory yourself
pip install -e .[ui]
ollama pull qwen2.5:3b-instruct && ollama pull llama3.2:3b
python -m forge ui                       # web UI: build, results, chat
python -m forge run --brief-file brief.txt --docs my_docs/ --config configs/ollama_small.toml --non-interactive
